⚡ Supabase Integration

Connect your Supabase project to persist all data in the cloud

🔥 Step-by-Step Setup: Pehle supabase.com par free project banao, fir yahan credentials daalo. Schema auto-create ho jayega.

🔗 Connect Supabase

📋 SQL Schema (Run this in Supabase SQL Editor)

Neeche SQL already ready hai. "Open SQL Editor" dabao → naya tab khulega → SQL paste karo → RUN dabao.

-- RestroMind System Hub — Tables CREATE TABLE IF NOT EXISTS public.tasks ( id TEXT PRIMARY KEY, title TEXT NOT NULL, description TEXT DEFAULT '', status TEXT NOT NULL DEFAULT 'todo', tags JSONB DEFAULT '[]'::jsonb, created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW() ); CREATE TABLE IF NOT EXISTS public.credentials ( id SERIAL PRIMARY KEY, label TEXT NOT NULL, value TEXT NOT NULL, created_at TIMESTAMPTZ DEFAULT NOW() ); -- Row Level Security (allow anon access) ALTER TABLE public.tasks ENABLE ROW LEVEL SECURITY; ALTER TABLE public.credentials ENABLE ROW LEVEL SECURITY; CREATE POLICY "Allow anon all" ON public.tasks FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "Allow anon all" ON public.credentials FOR ALL USING (true) WITH CHECK (true);

📌 Steps to Setup

1

Create Supabase Project

Jaao supabase.com → Sign up → "New Project" → Name: restromind-hub → Database Password set karo → Region choose karo → "Create new project"

2

Get API Credentials

Project Settings → API mein jaao. Project URL aur anon public key copy karo. Upar ke Connect section mein daalo.

3

Create Tables

"Open SQL Editor" button dabao — SQL copy ho jayega aur Supabase SQL Editor khul jayega. Wahan paste (Ctrl+V) karo aur RUN dabao.

4

Push Data

Tables ban jaane ke baad "Force Sync All" button dabao. Uske baad data automatically sync hota rahega.
